Project Description

A minimalist, high-performance Sales and Inventory Management System designed specifically for a bakeshop environment. 
It is built to handle daily transactions, track ingredient stock levels, and provide real-time sales insights while maintaining a clean, distraction-free user interface.

Setup Instructions

Install XAMPP

Open phpMyAdmin (http://localhost/phpmyadmin).
Upload the database
Open your browser and go to http://localhost/malou-bakes.
Login
